# Atividade prática de PySpark — Rocket Lab Dados

Resolução da atividade de introdução ao PySpark, desenvolvida no Databricks.

## Conteúdo

- Leitura e exploração de dados.
- Filtros e junção de DataFrames.
- Cálculo do overall médio por nacionalidade.
- Classificação dos jogadores por overall.
- Montagem da seleção brasileira na formação 4-4-2.
- Desafio bônus: seleção da melhor carta de cada atleta, evitando jogadores repetidos.

## Tecnologias

- Python
- PySpark
- Databricks
- Jupyter Notebook (`.ipynb`)

## Como executar

1. Importe o arquivo `RL_Dados_2026_2_Atividade_PySpark.ipynb` no Databricks.
2. Adicione os dados dos arquivos .csv.
3. Execute as células na ordem apresentada.
